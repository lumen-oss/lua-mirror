# Lua mirrors

A mirror of the PUC-Rio Lua source releases.

It hosts the newest patch release of every Lua 5.1+ minor, as published on
<https://www.lua.org/ftp/>.

The mirror is updated daily by
[`mirror.yml`](.github/workflows/mirror.yml), which runs
[`scripts/update-mirror.sh`](scripts/update-mirror.sh).
